Coursework

Class projects and coursework demos.

Analog PID

  • Final project for Analog Electronics course
  • Utilizes Op-amps to create a PID control loop
  • PID controls the position of the DC motor
  • Proportional and Derivative terms had adjustable gains
  • Transistors used to amplify current

Hand Robot

  • Final project for Robotics System Design course
  • The objective was to create a hand robot that can automatously navigate a maze
  • TOF sensors gathered data for simple navigation
  • Raspberry Pi used as controller

LiDAR bot

  • Final project for Microcontroller Architecture course
  • Assembled with 3D printed parts, 2D Planar LiDAR, STM32, and motors
  • Programmed using only RISV-V assembly
  • Utilized UART communication to send LiDAR data to STM32 board

SimScape Propeller Car Modeling
  • Final project for Applied Dynamics Systems class
  • The goal of this project is to model a dynamic system in MATLAB SimScape and compare the simulation with a physical demonstration
  • Our team chose to model a downwind propeller car inspired by the Veritasium science YouTube channel
  • This project involved 3D printing parts, C++ programming to collect sensor data, Simulink Multibody to model every component, and the parameter estimation MATLAB app to ensure the digital model matched the experiment
