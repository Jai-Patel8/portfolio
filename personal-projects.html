Personal Projects

Independent builds and experiments.

Distance sensor particle filter

  • This project involves using the Webots simulation software to control a mobile robot with two distance sensors and an IMU
  • ROS2 is used to communicate between subsystems in the program
  • Simulation is used to experiment with particle filtering for localization
  • Particles can be visualized with the black window, white pixels are guessed positions
  • The red dot is the weighted average position for each white pixel

TAMU Hack '25

  • Robot in 24 hours
  • Tracks 17mm green projectiles using a computer vision model
  • Created with 3D printed parts, cardboard, Intel Realsense, NVIDIA Jetson, motors, and motor controllers

PSO PID tuning

  • Program created to tune motor PIDs faster and easier for First Tech Challenge
  • The software uses a machine learning algorithm called Particle Swarm Optimization(PSO)
  • Works by testing random gain values, and converging to optimal values
